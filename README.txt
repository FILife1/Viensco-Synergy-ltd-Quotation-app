VIENSCO SYNERGY LTD – quotations, invoices, purchase orders (flat version: every file in one folder)

PUT IT ONLINE (free, one time)
1. GitHub > open your repository > Add file > Upload files > upload the files from this folder (replace the old ones) > Commit.
   Upload the LOOSE files only - do not upload the .zip (GitHub does not unzip it). If a batch fails, upload 3-4 files at a time.
   The old file manifest.webmanifest can be deleted from the repository: the app now uses manifest.json.
2. Settings > Pages > Branch: main, folder: / (root) > Save. Your link: https://YOURNAME.github.io/REPO-NAME/

INSTALL (open the https link, wait a few seconds so files are saved)
- Android (Chrome): tap Install on the bar at the top, or menu (3 dots) > Install app.
- iPhone / iPad: Safari > Share > Add to Home Screen.
- Windows / Mac (Chrome or Edge): install icon at the right end of the address bar, or menu > Install.
- Settings > Install app shows an "Install check" and a "Show install notice again" button.
- If you installed the older "Viensco Docs" app, uninstall it first, then install this one.

EXPORT: open any document > Download PDF / Save image / Share PDF / Print.

AFTER YOU CHANGE ANY FILE: edit CACHE at the top of sw.js (viensco-synergy-v3 -> v4).
Your data stays on the device (same browser storage as before). Use Settings > Backup regularly.
